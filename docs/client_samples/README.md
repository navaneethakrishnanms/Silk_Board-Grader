# Client sample scans (put the real files here)

WP4 tunes the engine on the laboratory's own scans. Place them in this folder:

| File | What |
|---|---|
| `fabric_sheet.*` | the composite / fabric sheet scan (printed specimen, white lustrous strip, light-blue strip, original fabric) |
| `grey_scale_change_p1.*`, `grey_scale_change_p2.*` | colour-change grey scale, 2 pages |
| `grey_scale_staining_p1.*`, `grey_scale_staining_p2.*` | staining grey scale, 2 pages |

Then run the commands at the end of `../tuning/CHANGELOG.md`. Until then the tools were exercised on
SYNTHETIC stand-ins in `../client_samples_synthetic/`.
